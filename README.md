# AI Tools Lab

AI Tools Lab is a beginner-friendly Python project created as part of a college practical exercise. The project demonstrates basic Python programming, sorting algorithms, utility functions, and Git/GitHub version control.

## Project Description

This project contains Python programs developed to practice programming concepts and GitHub workflows.

### Features

- Bubble Sort algorithm
- Palindrome checking
- Word counting
- Celsius to Fahrenheit conversion
- Git and GitHub version control
- Feature branches and Pull Requests
